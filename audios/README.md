# audios

This folder holds background music and audio assets used in the Entertainment-Haven project.

Guidelines
- Place audio files here (e.g. .mp3, .ogg, .wav).
- Keep filenames lowercase and use hyphens or underscores instead of spaces (example: bg-music_intro.mp3).
- If any audio file is larger than 100 MB, use Git LFS: https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage
- Add a short README entry near the file if licensing or attribution is required.

If you want, I can add an example placeholder audio file or set up Git LFS configuration for large files.
